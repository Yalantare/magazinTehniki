# Магазин Техники (magazinTehniki)

Командный проект интернет-магазина техники с современной микросервисной архитектурой:
- **API (Бэкенд):** Python (FastAPI, SQLModel, Uvicorn)
- **База данных:** MySQL 8.0 (Docker-контейнер с пробросом порта `3307`)
- **Клиентская часть (Web):** Vue 3 + Vite
- **Панель управления (Admin):** C# / WPF (.NET 8)

---

## База данных: Подключение и параметры

База данных MySQL разворачивается в Docker-контейнере `shop-db-1`.  
Внешний порт настроен на **`3307`** (вместо стандартного `3306`), чтобы предотвратить конфликты с локально установленной на Windows службой MySQL (например, `MySQL95` или XAMPP). Внутри Docker-сети база по-прежнему работает на стандартном порту `3306`.

### Реквизиты подключения по умолчанию

| Параметр | Значение для хоста (вашего ПК / DBeaver) | Значение внутри Docker сети |
| :--- | :--- | :--- |
| **СУБД** | MySQL 8.0 | MySQL 8.0 |
| **Хост (Host)** | `localhost` или `127.0.0.1` | `db` |
| **Порт (Port)** | `3307` *(или настроенный в .env)* | `3306` |
| **Имя базы (Database)** | `shop` | `shop` |
| **Пользователь (User)** | `root` | `root` |
| **Пароль (Password)** | `root` | `root` |
| **Кодировка** | `utf8mb4` | `utf8mb4` |

### Строки подключения (Connection Strings)

- **SQLAlchemy / SQLModel (Python при запуске на ПК):**
  ```text
  mysql+pymysql://root:root@localhost:3307/shop?charset=utf8mb4
  ```
- **Стандартный MySQL URI (для хоста):**
  ```text
  mysql://root:root@localhost:3307/shop
  ```
- **C# / .NET (при прямом подключении к MySQL с ПК):**
  ```text
  Server=localhost;Port=3307;Database=shop;Uid=root;Pwd=root;Charset=utf8mb4;
  ```

## Подключение к бд через графические клиенты (DBeaver, DataGrip, MySQL Workbench, VS Code)

Самый удобный способ для просмотра и редактирования таблиц:

1. Запустите контейнеры:
   ```bash
   docker compose up -d
   ```
2. Откройте ваш GUI-клиент (например, **DBeaver** или **DataGrip**).
3. Создайте новое подключение к **MySQL**.
4. Укажите параметры:
   - **Host:** `localhost` (или `127.0.0.1`)
   - **Port:** `3307`
   - **Database:** `shop`
   - **Username:** `root`
   - **Password:** `root`
5. Нажмите **Test Connection** (Тест соединения). При первом подключении клиент может предложить скачать драйвер MySQL — подтвердите скачивание.
6. Нажмите **Finish** / **Connect**.
